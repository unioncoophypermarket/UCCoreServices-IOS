# 🧱 UCCoreServices-iOS

**UCCoreServices-iOS** is a foundational **Swift Package** developed for the **UnionCoop Mobile App** ecosystem.  

It provides all shared core functionalities and reusable components required by other modules such as:  
- 🔐 **SSO (Single Sign-On)**  
- 🛒 **E-Commerce**  
- 📱 **Scan & Go**  

This package establishes the **core infrastructure layer** that standardizes networking, configurations, environment management, and shared utilities across all iOS modules — ensuring **consistency**, **maintainability**, and **modular scalability**.

---

## 🎯 Purpose

UnionCoop’s iOS application follows a **modular Clean Architecture** approach.  
`UCCoreServices` serves as the **foundation layer** that each feature module depends on, avoiding code duplication and enforcing architectural consistency.

---

## ✅ It Ensures

- **Unified API communication standards** across all modules.  
- **Centralized environment and configuration management.**  
- **Consistent error handling** and **response decoding.**  
- **Shared reusable utilities** such as `Logger`, `Loader`, and `Alert System.`  
- **Strict separation of responsibilities** between feature modules for cleaner, testable code.
